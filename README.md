# Jarvis PWA v3

新增：分层记忆、动态历史检索、长期计划、进度复盘、7/30/90天总结。

部署：
1. 整个文件夹上传 GitHub。
2. Vercel 新建项目，Framework 选 Other。
3. Settings → Environment Variables 添加 OPENAI_API_KEY。
4. 可选 OPENAI_MODEL=gpt-5-mini。
5. 重新部署。
6. iPhone Safari 打开网址 → 分享 → 添加到主屏幕。

数据默认保存在手机浏览器/PWA本地；请定期在“记忆”页导出 JSON 备份。


## v3 新增：先澄清、后判断

对于感情、职业、重大消费、人生规划、健康等容易误判的问题：
- Jarvis 会先检查数据库里是否缺少会显著影响结论的关键事实。
- 如果缺少，就暂停判断，只问 1-3 个最关键问题。
- 待回答问题会保存在本地，不会因为关掉 App 就丢失。
- 你补充后，Jarvis 再继续分析。
- 如果仍不够，它可以继续追问，但不会自作主张下结论。

导出备份时，待回答问题也会一起导出。
