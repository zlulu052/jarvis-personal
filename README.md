# Jarvis PWA v5.1 · 私人综合洞察版 (CloseAI)

在 **v5.0.2 私人修复版**基础上增量升级。本项目属于私人版，不是粉丝公开使用的 BYOK 版。继续使用你在 Vercel 配置的 CloseAI API Key。

## 本版重点升级

- **全方位综合分析（默认）**：所选时间范围内的全部记录先在本机参与统计，分析不再只依赖高频标签；自动查看多个生活领域、少见但重要的事件和时间邻近线索。
- **高频主题 / 指定主题**：保留单领域深入分析，且不会忽略相关的睡眠、工作、学习、情绪等其他领域。
- **三级检索**：全局扫描全部范围内记录，按领域/时间跨度/重要性抽取代表性证据（最多约 65 条）供模型阅读，附上原始追问与补充回答；范围外重要事件另作为背景上下文。注意：全部记录参与本机统计，但不是将全部原文发送给模型。
- **可核对的证据**：AI 的每条重点观察可附记录编号，点证据链接回看原文与补充回答。程序会剔除模型编造或无效的记录编号。
- **区分观察与假设**：提示词要求陈述事实、讨论替代解释、说明数据缺失及 AI 估算指标的限制，不能把时间共现当作因果证明。
- **历史报告**：分析报告保存在本地 IndexedDB，重新打开仍可查看；报告不会自动覆盖以前的原始记录。
- **行动实验**：AI 建议可加入本地追踪，记录每日执行情况，结束时做自评；下一次分析可以参考这些执行结果。
- **敏感记录控制**：综合洞察默认不把含内置「感情」标签的记录发给模型，也不发送整个用户档案与历史摘要。用户手动勾选才启用这些私人内容。本开关只控制综合洞察，其他既有功能按其原有机制运行；若记录敏感性未被正确打上标签，应谨慎开启分析。
- **备份迁移**：扩充 JSON 导入/导出，包含新报告和行动实验；数据库沿用 `jarvis_v4_db` 并通过版本升级新增 Object Store，不清空旧记录、计划、标签、问答。
- **时间范围**：7 / 30 / 90 / 365 天以及全部。

## 更新部署

1. **在当前私人版 Jarvis 先导出 JSON 备份**，保存到自己的电脑或手机文件。
2. 解压此包，将**里面的文件和 `api/` 文件夹**覆盖上传到私人版的 GitHub 仓库根目录（不要上传压缩包本身，也不要多套一层目录）。
3. GitHub 提交后等待 Vercel 的新 Production 部署 Ready。
4. 重新打开原网址；有旧版缓存时关闭 PWA 重开，必要时检查 Service Worker 更新。
5. 进入「洞察」，选择时间范围和分析模式，再点击分析。

### 环境变量（保持私人版原配置）

```text
OPENAI_API_KEY=你的 CloseAI Key（请勿写到 GitHub 文件）
OPENAI_API_BASE=https://api.openai-proxy.org/v1
OPENAI_MODEL=你当前可用的模型名称
```

如需已有的问答联网搜索，仍使用原来的 `TAVILY_API_KEY`（可选；与本次综合洞察无直接关系）。

## 数据与隐私说明

- 日常记录、补充回答、计划、历史问答、分析报告和行动实验主要存储在当前浏览器的 IndexedDB 中；不同浏览器和桌面 PWA 可能不能共享本地数据，请定期备份。
- 综合分析执行时会把精选原文、结构化统计、相关补充回答及用户允许发送的上下文交给 Vercel 后端与所配置的第三方模型服务。本地存储不意味着模型分析时数据永不离开设备。
- 关联分析提供**值得验证的假设**，不是临床诊断，也不能由记录共现推断确定因果。
- 新版报告不会自动替用户更改原始记录；点击证据引用时会读取现有记录。若之后删除了原文，该证据引用将无法打开。
