# Jarvis PWA v5.0.1

在 v4.1 基础上升级：

- 记录长文本优化：列表支持「展开全文 / 收起」，新增完整记录详情页、复制原文、编辑原文；不会因为卡片折叠而看不到旧记录。
- 情绪 / 精力 / 压力支持 1-10 数值，手填优先，AI 可在信号较清晰时保守估算并标注来源。
- 新增图片识别：图片压缩后仅在用户主动识图/分析时发送模型，识别结果可进入记录。
- 标签现在都可以删除；删除标签不会删除历史记录。
- 洞察升级：高频标签、标签共现、相关事件、心理学/行为科学解释、具体行动与验证指标。
- 新增「Jarvis 问答」与专题空间（含全局问答、关系专题），会结合长期记录回答，信息不足先追问。
- 备份格式升级为 v5，包含专题空间与问答历史。

部署方式与 v4.1 相同：Vercel 环境变量仍使用 `OPENAI_API_KEY`、`OPENAI_API_BASE`、`OPENAI_MODEL`。图片识别要求当前模型支持视觉输入。

> 注意：本地数据库保存在 IndexedDB，但进行 AI 分析/识图时，相关文本或图片会发送到你配置的模型 API。
# Jarvis v4.1 · CloseAI 可视化版

这是一版完整重构，不再只是聊天页。

## 新增

- 首页仪表盘：本月记录、连续记录、活跃计划、高频标签
- 快速记录：仅记录 / 记录并分析

- 自动标签：AI 从已有标签库中自动分类
- 手动纠错：每条记录可重新选择标签，纠错示例会提供给后续分类参考
- 自建标签：可以新增、改名、删除自定义标签
- 记录页：关键词搜索、时间筛选、状态筛选、标签筛选
- 洞察页：心情、精力、压力、睡眠、体重、运动、阅读趋势曲线
- 标签频率图
- AI 趋势解读
- 长期计划：计划生成、进度汇报、复盘、下一步清单

- JSON 导出/导入
- v3 数据自动迁移：同一 Vercel 域名升级后，会读取 v3 localStorage 并迁移到 v4 IndexedDB

## CloseAI / Vercel 环境变量

保留你现在已经配置好的三个变量即可：

```text
OPENAI_API_KEY=你的 CloseAI Key
OPENAI_API_BASE=https://api.openai-proxy.org/v1
OPENAI_MODEL=gpt-6-luna
```

不用重新生成 Key。

## 本地数据与隐私

长期数据库默认存在当前设备的 IndexedDB 中，不使用 iCloud，也没有单独的云端数据库。

但当你点击“记录并分析 / AI 解读 / 生成计划”等功能时，为了让模型分析，本次所需上下文仍会发送到你配置的 CloseAI 接口。

## 图表怎么获得数据

趋势图不会凭空猜数字。数据来源有两种：

1. 记录时手动填写“心情 / 精力 / 压力 / 睡眠 / 体重”；
2. 文字里明确出现可无歧义提取的数据，例如“昨晚睡了6小时”“今天跑了40分钟”，AI 分析时会提取。

## 标签纠错如何工作

AI 自动分类后，你可以进入“记录”页面 → “编辑标签”。

每次人工修改都会保存一条本地纠错示例。以后分析时，最近的纠错示例会发给模型，作为你的个人分类偏好参考。

你还可以在“设置 → 标签管理”中创建自己的标签，例如：

- 社区工作
- 编制考试
- 暧昧对象
- 减脂期
- 重要复盘

之后这些标签会自动进入 AI 可选标签库。

## 备份

Jarvis 会实时写入 IndexedDB，并最多保留 10 个本地恢复点。

不过手机本地数据库仍不是绝对永久存储。建议偶尔：

设置 → 备份与恢复 → 导出完整备份

在 iPhone 上选择“文件 → 我的 iPhone”保存即可，不需要 iCloud。
